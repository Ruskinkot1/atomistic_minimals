# Задачи команды (5 человек)

Цель: статья про смягчение ППЭ в универсальных MLIP и про то, ловит ли его неопределённость.
Всё локально: только инференс и небольшой fine-tuning открытых моделей.
Ветка: `claude/gallant-bell-e79ppq`. Код в `src/curvature_fidelity/`, скрипты в `scripts/`, текст в `paper/`.

## Участник 1. Литература и новизна
- [ ] Прочитать целиком: arXiv:2405.07105 (Deng), 2507.21297 (Heterogeneous Ensemble), 2603.10159 (Wong & Yang).
- [ ] Поискать на arXiv и OpenReview за 2026 год: "softening" + "uncertainty", "curvature", "Hessian calibration", "vibrational frequencies MLIP".
- [ ] Обновить `docs/novelty_search.md`: что именно уже сделано, что нет.
- [ ] Написать разделы Introduction и Related Work в `paper/main.tex`, добавить ссылки в `paper/refs.bib`.
- Результат: вывод «тема свободна / сузить», и готовые два раздела.

## Участник 2. Кристаллы: фононы
- [ ] Установить `mace-torch`, `chgnet`, `matgl`, `phonopy`.
- [ ] Взять 50-100 кристаллов с DFT-фононами (например, из открытой базы фононов Matbench/MDR).
- [ ] Для M3GNet, CHGNet, MACE-MP-0 посчитать фононные частоты, сравнить с DFT.
- [ ] Посчитать масштаб смягчения (`softening_slope`) и ошибку частот (`frequency_mape`).
- Результат: `scripts/run_crystals.py` и таблица `results/crystals.csv` (материал, модель, масштаб, ошибка частот).

## Участник 3. Молекулы: колебательные спектры
- [ ] Подобрать набор малых молекул с эталонными DFT-частотами (QM9-подобный или из открытых данных; зафиксировать функционал).
- [ ] Прогнать MACE-OFF и MACE-MP-0 (и ещё 1-2 открытые модели, если доступны).
- [ ] Посчитать Гессиан (`numerical_hessian`) и частоты (`vibrational_frequencies`), сравнить с DFT.
- [ ] Проверить, что `numerical_hessian` согласуется с автодиффом на 3-5 молекулах.
- Результат: `scripts/run_molecules.py` и `results/molecules.csv` в том же формате, что у участника 2.

## Участник 4. Неопределённость
- [ ] Собрать ансамбль: несколько моделей или несколько сидов одной модели.
- [ ] Реализовать вторую оценку: расстояние в латентном пространстве (эмбеддинги модели).
- [ ] На данных участников 2 и 3 проверить: растёт ли неопределённость там, где сильнее смягчение, а не только там, где больше ошибка. Считать корреляцию со смягчением отдельно от корреляции с абсолютной ошибкой.
- [ ] Нарисовать графики: неопределённость против масштаба смягчения.
- Результат: `scripts/run_uncertainty.py`, `results/uncertainty.csv`, 2-3 рисунка.
- Зависит от: данные участников 2 и 3 (начать с заглушек на тех же колонках).

## Участник 5. Коррекция и бенчмарк
- [ ] Реализовать два дешёвых метода: (а) fine-tuning на одной дополнительной точке (база из Deng et al.), (б) калибровка по Гессиану на нескольких точках.
- [ ] Сравнить их по масштабу смягчения до и после.
- [ ] Оформить бенчмарк «curvature-fidelity»: единая функция оценки и единый формат таблиц для кристаллов и молекул, README с протоколом запуска.
- [ ] Написать разделы Methods и Experiments (коррекция) в `paper/main.tex`.
- Результат: `scripts/run_correction.py`, `src/curvature_fidelity/benchmark.py`, `results/correction.csv`.

## Общие правила
- Формат таблиц: колонки `system, model, domain, functional, ref_value, pred_value, softening_scale, freq_mape`.
- Один участник — одна папка скриптов и одна ветка `feature/<имя>`; в основную ветку через PR.
- Данные не коммитим (`data/` и `results/` в `.gitignore`), в README пишем, откуда скачать.
- Все числа воспроизводятся одной командой из `scripts/`.
